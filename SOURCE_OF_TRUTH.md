# Source-of-Truth Policy

**Binding on every agent and every worker. Written 2026-09-30.**

| domain | authority | never duplicate it in |
|---|---|---|
| Code, workflow, notes | **GitHub** `ChihHsuan-Yang/AAMAS2027-AgentProtocols` | anywhere else |
| Manuscript | **Overleaf** `git.overleaf.com/6abae70ebd16e2dc9cdecee6`, mirrored from `paper/` | — |
| Large structured data | **`experiments/results/FROZEN/`** locally; `hf_artifact/` when released | — |
| **Every numeric literal** | **`FROZEN/` + `analysis/scripts/FINAL_TABLES.py`** | prose, notes, figures, READMEs |
| What may be claimed | **`APPROVED_CLAIMS.md`** | — |

## The rule that matters

**No number is maintained by hand anywhere.** Every figure in the manuscript,
every label in a plot, every value in a README traces to a run of
`FINAL_TABLES.py` against the sha256-manifested frozen snapshot. A number that
cannot be regenerated by that command is not a number this project reports.

This exists because the project has already produced four wrong figures by
copying a value from one artifact into another and letting the source change
underneath it.

## Manuscript sync discipline

`paper/` (GitHub) and Overleaf must not diverge. After any milestone:
compile, push to Overleaf, **verify the remote commit hash changed**, confirm
the PDF builds there. An earlier state of this project had the real manuscript
in GitHub while Overleaf held a stub for two days; that must not recur.

## Frozen snapshot

`experiments/results/FROZEN/MANIFEST.json` carries sha256 per file and the
per-cell census. Denominators do not change after the freeze. If a denominator
must change, that is a re-freeze with a new manifest and a recorded reason,
never a silent edit.
